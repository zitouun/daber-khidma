# Dabber Khdma — Brand & Landing Pack

Creative, editable brand kit plus standalone production-oriented landing page frontend. **Concept stage**; business, legal and technical approval still required.

- `brand/`: horizontal logo, symbol, inverse logo, favicon, design token JSON
- `landing/`: responsive HTML/CSS/JS and live preview instructions
- `docs/BRAND_GUIDELINES.md`: brand strategy, messaging, color, typography, usage rules, backend handoff

To preview: `python -m http.server 8080`, then visit `http://localhost:8080/landing/`.

The early-access form is intentionally disabled for actual collection until your Spring Boot endpoint is configured. No user data is saved by the demo.

Important: Trademark/domain clearance has NOT been completed. A similarly named shorter marketplace brand `Dabber` appears in public web search results. Perform clearance before launch.
